# 第九阶段前置方案：同证据流的时点重放

2026-11-14。在首次运行前保存，不声称外部预注册。

目标对应 CQ5（撤销）、CQ7（政策变化）、CQ9（新增材料影响）。同一合成材料按时点揭示，任何方法不能读取未来事件。不是模型生成研究，不读取密钥、不调用模型服务。

六条轨迹各六个时点，含撤销、数量修订、权限变化、政策切换、关联冲突及渐进补证。36 个观察不是36个独立业务样本。标签由本轮作者预先写入，非独立专家金标准；策略函数不接收标签。

主要配对：A 每时点重新执行全部4个业务谓词；B 每时点检查全部4组依赖，只有值变化影响的谓词重算。两者使用相同输入、业务语义和全部可见证据，没有B独占材料。B 即使旧结论关闭也必须响应更新。C 仅首次计算而永远缓存，是明确弱负对照，不能用 B-C 宣称优于强基线。

主观察：逐时点决策一致性、不得关闭时的错误关闭数、从close到非close的撤回是否在同一事件完成。资源代理：业务谓词求值数、增量依赖组检查数、缓存写入数、共同输入字段更新数与共同结论聚合数分别报告，不相加冒充时间。检查依赖/缓存并非免费，拒绝从谓词少算直接推出总成本减少。

无真人分钟、无模型建模成本；不计算显著性或泛化区间。保留所有轨迹和全部失败。顺序由业务时间决定而非随机打乱；补充测试未来信息隔离与无关字段、重复值不变性。所有输出重跑字节一致。不改已有阶段。
