# 第三阶段执行计划：政策规则基线

日期：2026-11-08。计划在本阶段预测和评分之前写入本地文件；不是外部预注册。

## 目的

为后续 AI 辅助本体建模建立一个实际计算交易判断、而不是回放答案的确定性规则基线。它回答“六份明示政策能否被一个独立编写的程序执行”，不回答“分批建模是否优于全量建模”。

## 作者输入与边界

基线实现者只收到六份 model-facing 政策材料、通用案例信封和预测字段契约，不读取交易评价案例、标签、生成脚本、来源登记表或旧解释器。实现者自己编写政策边界测试。这个限制通过任务约束和读取清单记录，不是操作系统强制访问控制，也不是独立人类盲审。协调者读取过上一阶段报告及 F01 的部分开发案例，因此不能将整个流程称为全盲。

程序是 AI 辅助人工式编写的 Python 规则实现。它利用已结构化、与文本一致的 facts，不做 OCR、文本语义抽取、开放式本体发现或模型训练。不把编写程序的内部 AI 活动计作固定版本/计量的模型实验。

## 执行顺序

1. 只从政策实现六个家族的规则，运行自拟单元与变形测试，独立代码审阅。
2. 冻结实现、测试、运行器、材料及评分器的 SHA256 清单。
3. 用冻结程序读取全部 60 条已冻结交易，先写出三个 split 的完整预测。
4. 运行前完整性检查会对包含标签在内的冻结文件读取字节并计算哈希，但不解析标签内容。三个 split 的预测文件全部持久化之后，评分步骤才解析标签；记录全部案例及所有失败，不因结果不理想替换或删掉案例。
5. 重跑同一程序核对预测及核心结果的字节一致性。冻结之后的缺陷修复必须另记版本和首次结果，不能默默覆盖。

## 预定指标

- 完成率、三态判断正确数/总数、错误关闭数/全部负例、可关闭召回率及逐家族结果。
- 主理由精确匹配，单独记录，不能把仅判断正确当作推理正确。
- 来源位置存在率只是引用定位检查；语义支持率与真人审阅耗时保持空值。
- 同时报告全送审、全关闭两个固定常数参考，明确它们不是有竞争力的建模方案。
- 不计算将少数人工构造政策家族当作 IID 自然样本的置信区间。

## 模型与费用

当前未确认一个同时满足固定模型身份、真实 token 计量、无需新增费用的可复现实验后端。没有尝试付费调用，也没有把尚未调用说成工具失败。今天的规则执行仅使用 Python 标准库、已有合成材料和本地计算。

## 结论限制及下一步

即使 60/60 通过，也只说明这个结构化合成任务的规则实现与标签相符，不能证明本体建模有效、模型优越、真实业务准确率、零风险或节省人工时间。规则手写成本没有真人测量。

后续仍需冻结可由 A/B 模型共同生成的可执行表示及解释器；本阶段的家族专用 Python 规则不冒充通用表示。确认适用模型后端后，先做开发/验证阶段真实生成，再按原公平性契约开展一次测试评价。
