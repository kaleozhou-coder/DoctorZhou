# Stage 12 frozen design
Four packet variants: short/long crossed with CR-17 at the start/end. Each has identical essential policy and six open questions plus six snapshots. Long inserts 32 clearly irrelevant archive notes; this is synthetic distractor length, not realistic diversity. CR-17 position is manipulated at document level, not every supporting evidence span.

For each variant run three fresh no-history workers:
- one: all ordered documents, one final output.
- batch: first ordered slice, interim output and gaps; receive remaining slice then revise once. Final material and order identical to other arms.
- strong: all ordered documents, draft; same material reviewed in a second turn before final.
No answer option enums are supplied. Questions still direct attention to target concepts, so not unguided ontology discovery. No executable OWL output. Conditions are proposed only.

Every cell is a new context (12 workers across four waves), no prior variant exposure. Worker isolation is instruction-only, not filesystem sandboxing. Fixed batching changes information-arrival timing when CR-17 moves; estimate neither an independent batch size effect nor retrieval policy effect. Length padding is constructed/repetitive and readily identifiable. Model version, seed, token budgets, wall-clock costs not controlled or measured. Global two-pass reads repeat more source content. No human gold/review; independent AI/manual rubric checks are exploratory.

Gold and packets are frozen before workers start. Free answers require semantic scoring against rubric; no exact string answer grading. Root reviews gold before start and scores anonymous outputs. Raw outputs preserved without post-hoc rewriting. Report every failed item and evidence gap; do not conclude equivalence or superiority from a single synthetic run.
