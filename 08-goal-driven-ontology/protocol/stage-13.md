# Stage 13 frozen protocol

Three arms: one-shot all sources, fixed first-four/last-five batches with revision, and two passes over all sources. Each arm runs independently for head/middle/tail; no shared state across rotations. Every final arm sees the identical evidence and question set. Batch first-pass conclusions are process-only, not compared fairly to final full information. N41 is in block positions 1/5/9; N08/N26 rotate together as well, therefore this measures whole document ordering, not a pure isolated single-clause-position effect. Multi-clause combination is assessed separately with hidden cases. Approximate word and character counts do not equal token usage; provider model version, token usage and human time unavailable. No human gold or paid API. Fixed batches are not autonomous search.

Freeze input and gold hashes before inference. Open answers scored by a separate anonymized AI reviewer for meaning, complete required evidence, and wrong applicable citation. Mentioning an inapplicable source as a rejected comparator is not a wrong citation. Model execution uses only extracted expression and cases, no source or LLM. Ten cases are withheld during extraction. Expression shape is not a complete OWL ontology. Strict-schema failures return unknown for every case and remain visible. A correct evaluator cannot prove source entailment, expert accuracy, production applicability or method equivalence. Report every per-layout paired outcome, false permissions, unknown decisions, citations and failures.
