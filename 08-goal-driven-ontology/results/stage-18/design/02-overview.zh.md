# 第18阶段 02 概要设计

证据包（带不可变版本的合成原文） → 人工可信登记（当前 CQ、允许来源/范围/角色、必需直接关系或精确补件） → 候选提案（值、引用或补件） → 确定性门禁 → ELIGIBLE / PENDING / BLOCKED。ELIGIBLE 仅准进入人工评审，不等于生效或发布；PENDING 可为正确的 UNKNOWN，但永不进入可执行分支。登记者与候选者隔离，独立夹具作者先定义外部判分；引擎不能看到 expected，不代理签署人。当前 ACL 是模拟，不是授权、来源认证或线上权限测试。此阶段无 LLM、付费、OCR、UI、真实 Runtime、真实业务数据，不改原项目。
