# 第 17 阶段 · 概要设计
输入为同一冻结合成包中原始 UTF-8 文档和限定问题，不给模型结构化字段值、金标或解释。模型以 JSON 提议确定值/未知及短原文引文。不把模型输出直接写入已发布本体。
处理顺序：1. 严格生成文本快照；2. 接收不可信模型 JSON；3. 用独立代码定位原文引文、记录派生表示范围和哈希；4. 对照预先冻结人工金标，分别计值匹配、锚点有效、直接支持；5. 输出报告和错误对照；6. 将实际变更及待做事项写回设计。
本阶段不是等预算分批对照。旧 UNKNOWN 留槽的比较另行预注册/冻结，至少六个独立材料家族否则只称可行性，不借一个文档包中几个字段冒充独立试验。
