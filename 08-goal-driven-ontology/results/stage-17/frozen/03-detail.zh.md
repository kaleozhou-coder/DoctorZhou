# 第 17 阶段 · 详细设计：纯文本证据锚点验证
文档逻辑 ID 与相对文件清单由调用者提供。每个文件严格 UTF-8、拒绝 BOM，CRLF/CR 转 LF 后 NFC，不折叠空白标点。存 raw SHA256、normalized UTF-8 SHA256 和固定 profile 标识。文档快照内使用 Python Unicode code point 位置 [start,end)，不是字节、UTF-16 或原 PDF 坐标。
候选文件严格形如 {"answers":[{"id":"Q...","status":"KNOWN","value":"...","evidence":[{"doc":"D...","quote":"逐字短引文"}]}]}。UNKNOWN 的 value 必须 null；不在材料中的文本不可当引文。每个问题必须恰好出现一次；引文同一文档内查找重叠出现，不能唯一定位时拒绝，先请求更长引文，不按第一处猜。引文只按规范后的精确字符匹配，代码不能判断所引句子是否为有效修订或是否支持结论。
设计接口由 reproduction/audit.py 提供独立实现；JSON 输出分别按题列出 VALUE_MATCH、ANCHOR_OK、JOINT。每题锚点至少一条且每条定位唯一才算机械通过。直接证据最低要求为金标预写的多组替代集合；任意一组完整覆盖才加分。必要短语限制按同文档引用包含来评估，错误作用域/草稿/越权句子可以精确定位但不等于支持。接受的额外引用必须来自金标许可来源范围，否则只作为语义偏差；同文件内额外引文不得和结论冲突之规则留人工。公开成绩注明这是冻结短语标签一致性，不等于完备的自然语言蕴含验证。
验收：至少一份实际隔离模型返回，记录时间/调用数/可见配置、不宣称可控实际 token；每条结果完整或明示失败。最低反例：真实但答错范围引文只过锚点；重复引文、修改的文档与引用不匹配、幻觉引文、UNKNOWN 缺失直接证据，不得给联合通过。机械单元测试加至少一组人工构造不可信输出。冻结全部文档/问题/金标/评分器后再发模型。遇无法满足的输入或执行行为在结果记录中回写，不静默改计分。
当前只做公开安全合成知识片段，无客户资料，无系统写入、发布/合并、租户与 ACL 实证。私有实验室已有发布约束，不在公开研究包中混写发布实现。
