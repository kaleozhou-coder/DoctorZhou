# 第 17 阶段 · 模型运行与计分协议
任务：从同一组纯中文文档，按给定问题提议范围明确的业务事实/约束。两次同提示隔离运行，每次同一模型族、独立上下文；非交叉 A/B，不以字段、多询问或两次同包当作独立样本。尽量无额外工具/上下文/重试；若一次格式错或模型没有返回，保留现状，计失败而不挑样。记录可见模型配置；内部调用无法获取实际 token 或采样温度时直陈未知。
冻结顺序：基础三设计 SHA → 数据、问题、参考标签、提示、评测器和测试 SHA → 模型工作 → 计分和有标识的故意坏输出。参考标签由 AI 制作者和主协调者预先审阅，不是经过外部领域专家签字的人工真值。原始支撑例是虚构合同语句，运行中不调用公开站点。
主要指标，分母全部问题：1 候选值+KNOWN/UNKNOWN 等于冻结标签；2 至少一条且所有引文在给定文档唯一定位；3 同时过去且满足该题至少一组预设直接支持短语，不得引用范围外文档。给出原因、行号或字符位置。编号、文档、哈希变化审计。不存在证据的 NEEDS_REVIEW 不当作通过，但允许储存候选供人工。
误用启动前设定：用相邻标段的真实价格/比例或同一文档的别条条款，句子可定位但证据不合格；制造不存在原文的引文；存在两处的短句不允许猜。这些控制是工程探针，不混入真实模型准确率。若错引精确句子同时仅修改分类/值，按原计分照录，绝不自动修/发布。
结果解释：REF_MATCH 是离线固定标签下可复现的近似指标，不是语言蕴含推理。出现真实但与材料权威相冲突的冗余证据，保留逐项人工设计审阅，不能因锚点正确就作为发布门槛。在真实平台还需强制项目/租户隔离、源修订身份和来源权限、文件类型及审批衔接。
